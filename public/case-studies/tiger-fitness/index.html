THE DETAILS MATTER

Useful answers.
No guesswork.

How are the web and mobile apps connected?

Both clients use the shared ASP.NET Core API. Staff and coaches manage gym workflows on the web, while members access their own plans, membership and recorded activity through scoped services.

Can members pay online?

The implementation supports Razorpay on the member web portal and native checkout in the mobile app when the gym enables and configures it. Settling a balance does not purchase a new membership period; renewal is separate.

What happens if connectivity drops?

The mobile app caches selected previously loaded information and supports offline workout recovery and synchronization. QR attendance and online checkout require connectivity.

Does nutrition include a food diary?

The app displays coach-assigned meals and planned macro targets. Food search filters the assigned plan; daily water entries are stored locally. Planned targets are not presented as consumed food or measured adherence.

Are these screenshots of the live app?

The web gallery uses existing desktop demo captures from this project. The mobile gallery uses reconstructed reference illustrations based on implemented Flutter flows, with sample data. These references do not imply an app-store release or live payment availability.
